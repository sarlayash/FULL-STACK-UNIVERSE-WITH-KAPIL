# Full Stack Universe with Kapil
> **Legacy of Values. Future of Learning.**
> **Philosophy:** 10% Theory, 90% Hands-On Software Engineering Pedagogy.

A comprehensive enterprise web application for **Java Full Stack** (Java 21, Spring Boot 3.3, React 19, PostgreSQL, Docker, Microservices) and **Python Full Stack** (Python 3.12, FastAPI, Django, Celery, React 19, PostgreSQL, Docker) powered by **Kapil**.

---

## 🌟 Key Features & Architecture

### 1. Dual Track Switcher
- **Java Full Stack Universe**: Core Java OOP, Spring Boot 3.3, Dependency Injection, Spring Data JPA & Hibernate N+1 tuning, Spring Security 6 with stateless JWT, Microservices, and Kafka event streaming.
- **Python Full Stack Universe**: Core Python Dunder Methods, FastAPI AsyncIO & Pydantic V2, Django ORM query optimization, Redis/Celery task queues, PostgreSQL JSONB indexing, and Dockerization.

### 2. Interactive Guided Demo Tour ("DEMO USER FOR A TOUR")
- Built-in multi-step guided tour walking learners and evaluators through every module without requiring manual configuration.
- One-click demo sign-in as **Alex Sharma** (Java Full Stack) or **Priya Patel** (Python Full Stack).
- Google Authentication simulation with real learner profiles and custom sign-in options.

### 3. Learning Studio (10% Theory / 90% Hands-On)
- **Student-Life Analogies**: Every core engineering concept explained through intuitive college/hostel/canteen analogies (e.g. Royal Enfield bike for Inheritance, Hostel dining hall for Dependency Injection, Single vs Multi-window ticket counter for Async/Await).
- **Industry Applications**: Real use cases from PhonePe, Swiggy, Zerodha, Netflix, and HDFC.
- **Production Code Snippets**: Clean, idiomatic Java and Python code with copy buttons.
- **Solved Examples & Interview Traps**: Deep technical explanations and common hiring FAQs.

### 4. Code Studio (Integrated IDE)
- Integrated code editor supporting Java, Python, and SQL.
- Interactive execution runner with compile-step simulation and realistic container sandbox terminal output.
- Automated test suite validating edge cases (e.g., PhonePe transaction deduplication, LRU Cache with $O(1)$ operations).

### 5. Industry Lab (4 Full-Stack Production MVPs)
- **ShopSphere (E-commerce)**: Live interactive storefront, Redis cart simulation, stock reservation locks, and payment webhook verification.
- **FinCore (Banking & FinTech)**: Core banking dashboard, simulated money transfers, ACID serializable locks, and cryptographic append-only audit ledger.
- **MediFlow (Healthcare Telehealth)**: Doctor schedule viewer, appointment booking, synthetic EHR, and live OPD token queue.
- **CampusOS (EdTech LMS)**: Academic enrollments, assignment submission auto-grader, and attendance criteria ($>75\%$) tracker.
- Includes **System Architecture Blueprints**, **Database ER Schemas**, and **REST API Specifications** for all 4 MVPs.

### 6. Assessment Arena & Placement Mock Tests
- Authenticated MCQs categorized by Java Core, Python Internals, Spring Boot, FastAPI, and Database Indexing.
- Kapil's Real Explanations and student-life analogies revealed upon answering.
- **Timed Placement Mock Test**: 10-minute countdown simulating TCS Prime, Amazon SDE, and FinTech machine rounds with percentile scorecards.

### 7. Deployment Hub (GitHub & Cloud CI/CD)
- Production-grade multi-stage `Dockerfile` (Java 21 Distroless / Python 3.12 Alpine).
- GitHub Actions CI/CD pipeline (`.github/workflows/deploy.yml`).
- `docker-compose.yml` orchestrating App, PostgreSQL 16, and Redis.
- Live interactive CI/CD pipeline deployment simulator.

### 8. Career Studio & Verifiable Certificate
- Placement readiness competency checklist across Level 01 to Level 05.
- Behavioral **STAR Method** answer templates (Situation, Task, Action, Result).
- Company hiring blueprints for TCS Digital, Amazon SDE-1, and Top FinTechs.
- Verifiable accredited completion certificate generator with unique verification ID and printable PDF format.

## 🚀 Running the Application Locally

1. **Navigate to the project directory:**
   ```bash
   cd C:\Users\LC\.gemini\antigravity\scratch\fullstack-universe-kapil
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```
   The application runs at `http://localhost:5174/` (or `http://localhost:5173/`).

3. **Build for production:**
   ```bash
   npm run build
   ```
